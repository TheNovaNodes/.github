# 🌌 TheNovaNodes — Organization Default Standards & Health Files

This repository contains organization-wide community health files, standards, and default templates for all repositories under [`TheNovaNodes`](https://github.com/TheNovaNodes).

## 🏛️ Included Global Defaults

- **Pull Request Template:** [`.github/pull_request_template.md`](.github/pull_request_template.md)
  - Enforces Issue binding (`Closes #___`), Scope Guard isolation, and the **Zero Dirty Hacks** quality checklist.
- **Issue Templates:** [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/)
  - `bug_report.md`: Minimal Reproducible Example (MRE) protocol.
  - `feature_request.md`: Architectural RFC proposal protocol.

## 🔗 Architecture & Protocols
For deep architectural manifests and agent coordination protocols, see [`TheNovaNodes/ecosystem-docs`](https://github.com/TheNovaNodes/ecosystem-docs).
