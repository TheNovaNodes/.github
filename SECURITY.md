# 🛡️ Security Policy — TheNovaNodes Ecosystem

## 1. Supported Versions

Security updates are actively applied to the latest releases and default branches of all official repositories within the [`TheNovaNodes`](https://github.com/TheNovaNodes) organization.

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `master` / `main` | :white_check_mark: |
| Latest Tagged     | :white_check_mark: |
| Older releases    | :x:                |

---

## 2. Reporting a Vulnerability (Responsible Disclosure)

TheNovaNodes team takes security, operational integrity, and secret isolation seriously.

If you believe you have discovered a security vulnerability or supply chain weakness in any repository, workflow, composite action, or agent protocol under `TheNovaNodes`:

> [!IMPORTANT]
> **DO NOT disclose vulnerabilities via public GitHub issues, discussions, or pull requests.**

### How to Report Privately:
1. **GitHub Private Vulnerability Reporting (Preferred):** Navigate to the specific repository's **Security** tab and click **Report a vulnerability**.
2. **Security Contact:** Email details to `security@thenovanodes.org` (or contact ЗавЛаб directly via authorized private communication channels).

### What to Include:
- Description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal proof of concept (PoC).
- Affected repository, branch, commit SHA, or workflow file.
- Any suggested remediations or mitigations.

### Response Timeline:
- **Initial Acknowledgment:** Within 48 hours.
- **Triage & Status Assessment:** Within 5 business days.
- **Coordinated Disclosure:** Fixes will be prepared, verified, and released before public announcement.

Thank you for helping keep the TheNovaNodes ecosystem secure!
